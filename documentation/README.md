# NetShield AI

## Project Overview

NetShield AI is an AI-powered cybersecurity platform developed during the Infosys AI Internship.

The platform provides:

- User management
- Role-based access control
- Team management
- Audit logging
- Network monitoring
- Packet capture
- Traffic analysis
- AI-powered threat detection
- Alert management
- Incident management
- Security analytics dashboard

## Technologies Used

- FastAPI
- React
- TypeScript
- Scikit-learn
- Pandas
- Scapy
- Docker
